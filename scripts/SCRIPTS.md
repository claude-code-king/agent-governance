# Scripts — agent-governance

One line per script; the scripter keeps it current; the orchestrator reads it before a scripter brief.

| script | what it does | files touched | arguments | adaptation: easy/medium/hard — what changes | one-off/reusable |
| --- | --- | --- | --- | --- | --- |
| `tools/cell_metrics.py` | per-run cell metrics, in context bands, aggregated | read-only; writes `cells.md`/`cells.json` + the reports | `--subagents-dir` (repeatable) `--agent-prefix` `--results-dir` `--dump-reports` `--md/--json/--out-dir` | easy — `BANDS` and the metric lists at the top of the script | reusable |
| `scripts/verifica-simplu.mjs` | the verifier the cells read: only items I1–I8 | read-only on the worktree; writes only `--json` | `<root> [--json <out>]` | medium — each item I is a separate block; exports `creeazaContext`/`itemiI` | reusable |
| `scripts/evalueaza-simplu.mjs` | the orchestrator's evaluator: imports the I items and adds T1–T5 + silent deletions | read-only on the worktree; writes only `--json` | `<root> [--report <md>] [--json <out>]` | medium — the T traps are tied to specific files/patterns | reusable |
| `hooks/agenti-vii.sh` + `hooks/test-agenti-vii.sh` | live-agent cap per session: start/stop/check, ask at >=4 | `/tmp/claude-hooks/live-<session_id>` (state only) | `start\|stop\|check`, env `AGENTI_VII_CAP` `AGENTI_VII_STALE` `CLAUDE_HOOKS_DIR` | easy — the cap and staleness come from env | reusable |
| `hooks/context-agent.sh` + `hooks/test-context-main.sh` | context budget for main and for agents, verification counter | only `/tmp/claude-hooks` (markers + log) | `--scope main\|agent` `--warn N` `--deny N` `--any-type` `--praguri-tip` | easy — `TYPE_LIMITS`, `AGENT_PREFIXES`, `SAFE_SUBAGENTS`, `PLAN_DIR` at the top of the script | reusable |
| `hooks/commit-gate.sh` + `hooks/test-commit-gate.sh` | ask on `git commit` touching .ts/.js/.mjs/.astro without a CONFORM audit | `/tmp/claude-hooks/audit-ok-<session_id>` (read-only) | `--extensii ts,tsx,js,jsx,mjs,astro`, env `CLAUDE_HOOKS_DIR` `COMMIT_GATE_GIT` | easy — extensions from the argument, the reason from `REASON` | reusable |
| `scripts/reanalyze-metrics.sh` | reruns `session_metrics.py` on each record's transcript in `metrics-local/`, so it picks up new fields | `metrics-local/*.json` (overwrites), reads `~/.claude/projects/*/<session>.jsonl` | `[--dry-run] [--limit N] DIR` | easy — `PROJECTS_DIR` and the excluded names (`pending-rating.json`, `cells*.json`) at the top of the script | reusable |
| `scripts/pricing-cache-5m.py` | writes prices into pricing.json + 5m/1h cache-write billing in the analyzer | `tools/pricing.json`, `tools/session_metrics.py` | `--pricing --metrics --price NAME=in,out,cread,cw5m,cw1h (repeatable) --note --date [--only F] [--dry-run]` | easy — prices come from `--price`; the 12 code anchors live in `RULES`, tested by `scripts/fixtures/pricing-cache-5m/test.sh` | one-off (rerunnable, idempotent) |
| `easy_install.sh` | one-shot install of agents/hooks/commands + settings.json, CLAUDE.md, orchestrare*.md into `$HOME/.claude`, with timestamped backup and restore | `~/.claude/{agents,hooks,commands}`, `~/.claude/{settings.json,CLAUDE.md,orchestrare*.md}`, writes `~/.claude-backup-<ts>/` | `[--dry-run] [--yes] [--restore <backup-dir>]` | easy — the copied lists (`INSTALLED_DIRS`, `INSTALLED_FILES`) are at the top of the script | reusable (idempotent) |
